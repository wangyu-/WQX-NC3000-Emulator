## 1. 实物键位清点

**左上角（喇叭孔旁边）两个圆键**

* `ON/OFF`
* `网络`

> 用户确认：这两个是**两个独立的实体按键，不复用**（不要和下面 6 个两档键混为一谈）。

> 矩阵位置备注：固件自己解出的开关键值 `0x18 = ONOFF_KEY` 落在矩阵 `(4,0)`；
> 但把它递给"刚被唤醒"的固件会让它立刻睡回去（已实测），所以模拟器的 F12
> 走 `(0,0)` + 热复位这条**可用**路径，`(4,0)` 暂时空着不用，等 ON 键那条
> 链路彻底做对再启用。

**上方功能区：12 个标签 = 6 个实体按键（每个键两档功能，按一次切换）**

```
娱乐 / 资讯      换算 / 计算      系统 / 时间
汉英 / 整句翻译   词库 / AHD       学习 / 剑桥
```

> 用户指出的重要一点：这 12 个标签**全是复用**的，例如"英汉/汉英"是同一个键——
> 按一次是英汉，再按一次变汉英。所以键表里应该是 **6 个条目、每个条目两个名字**，
> 而不是 12 个条目。（这也和 NC2000 的顶排键一样：`TKeyItem(..., "英汉", NULL, "汉英", ...)`
> 就是"主功能 + 副功能"两个标签。）

### 1.1 数字键是字母键的第二功能（不是独立按键）

红色小字就是"计算器模式"下的映射：

| 数字 | 物理键 | 矩阵位置（`--key-probe` 实测） |
|---|---|---|
| 7 8 9 | T Y U | (4,4)='t' (5,4)='y' (6,4)='u' ✅ 已通 |
| 4 5 6 | G H J | (4,5)='g' (5,5)='h' (6,5)='j' ✅ 已通 |
| 1 2 3 | B N M | (4,6)='b' (5,6)='n' (6,6)='m' ✅ 已通 |
| 0 | 符号 | (4,7) → **0x30 = '0'** ✅ 已通 |
| 小数点 | . | (5,7) → 0x2E ✅ 已通 |

**结论：数字不需要在模拟器里另配按键。** 这些物理键的字母键码已经全部实测可用；
数字键码是固件在"计算器模式"下对同一批键做的二次翻译。
所以"打不出数字"不是矩阵缺位置，而是**还没进去计算器模式**——
而"计算"键正好在那片待打通的 port6 功能区上（见第 4 节）。

**模拟器侧的现状（已核对 `key_new.cpp` 默认键表）**：PC 的数字键本来就映射到
同一批矩阵位置，与真机行为一致：

```
SDLK_1/2/3 -> (4,6)(5,6)(6,6)  = B N M
SDLK_4/5/6 -> (4,5)(5,5)(6,5)  = G H J
SDLK_7/8/9 -> (4,4)(5,4)(6,4)  = T Y U
SDLK_0     -> (4,7)            = 符号
```

所以这一块**不需要改**：按 PC 数字键 = 按设备上对应的字母键。

**机身侧面两个键（键盘图之外）**

* `红外接收按键`
* `单词精灵快捷键`

## 2. 矩阵的组织规律（本轮最关键）

把实物图与 `--key-probe` 的实测结果对齐后，规律非常干净：

**矩阵的"列"就是主键盘的"排"。**

| 矩阵列 | 实测译出的键 | 对应的实物排 |
|---|---|---|
| col 4 | Q W E R T Y U I（行 0–7） | 第一排 |
| col 5 | A S D F G H J K | 第二排 |
| col 6 | Z X C V B N M ⇞ | 第三排 |
| col 7 | 求助 中英数 输入法 跳出 符号 . 空格 ← | 底部功能排 |
| **col 0–3** | （待打通） | **上方 12 键功能区 + 网络 + 每排多出来的键** |

而每一排里"第 9、10 个键"（`O P 输入`、`L`、`⇧ ▲ ▼`）放不下 8 行，
所以它们和上方 12 键一起落在 **port6 的四条列线**上——这正好解释了
为什么数字键（T7/Y8/U9、G4/H5/J6、B1/N2/M3 的副功能）和机型键现在都还打不出来：
**它们全在那条没打通的 port6 线上。**

## 4. 热键位置已确认并验证通过（2026-09-26 第六轮）

固件里热键扫描是 **bank 3 `$4576`**：

```
依次把 $4628 的值写进 port1，再读 port0 的 bit0（"有键按下"公共线）
  $4628 = FE FD FB F7 EF DF BF 7F      ← 8 个"单条拉低"的列组 = 矩阵第 0 列的 8 行
命中后  LDA $4632,Y → STA $03E3 (Curr_Function)
  $4632 = 0C 04 02 00 01 06 08 0A
```

**所以"顶部那 8 个按键"就是矩阵第 0 列的行 0–7**，和用户给的实物信息完全对齐：

| 矩阵位置 | 按键（主/副功能） | PC 键 |
|---|---|---|
| (0,0) | 开/关 ON-OFF | `F12` |
| (1,0) | PDA / 游戏 | `F8` |
| (2,0) | 计算 / 换算 | `F9` |
| (3,0) | 时间 / 系统 | `F10` |
| (4,0) | 网络 | `F11` |
| (5,0) | 英汉 / 汉英 | `F5` |
| (6,0) | AHD / 词库 | `F6` |
| (7,0) | 剑桥 / 学习 | `F7` |
